# 🗄️ Aprendizado em Banco de Dados (Database Journey)

Bem-vindo ao meu repositório de estudos focado em **Banco de Dados**! Este espaço foi criado para registrar a minha evolução, desde os conceitos fundamentais até consultas e modelagens mais complexas. Aqui documento meus códigos, desafios e projetos práticos à medida que subo de nível.

---

## 🚀 Meu Momento Atual

Atualmente, estou consolidando meus conhecimentos em **Bancos de Dados Relacionais (SQL)** e o passo seguinte é os estudos em **Não-Relacionais (NoSQL)**. Meu objetivo é dominar a modelagem de dados e a otimização de consultas para criar aplicações mais eficientes.

---

## 📊 Nível de Conhecimento e Evolução

Abaixo estão as tecnologias que venho estudando e aplicando nos meus projetos:

### 🟢 Conhecimento Sólido (Dominando)
* **SQL Essencial**: Criação de tabelas, restrições (PK, FK) e relacionamentos.
* **Manipulação (DML)**: `INSERT`, `UPDATE`, `DELETE` e `SELECT` básicos.
* **Filtragem e Ordenação**: Uso de `WHERE`, `LIKE`, `IN`, `BETWEEN`, `ORDER BY`.

### 🟡 Em Evolução (Subindo de Nível 📈)
* **Consultas Avançadas**: Joins complexos (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
* **Funções de Agregação**: `GROUP BY`, `HAVING`, `SUM`, `AVG`, `COUNT`.
* **Modelagem de Dados**: Diagramas Entidade-Relacionamento (DER) e Normalização (1FN, 2FN, 3FN).

### 🔵 Próximos Passos (Na Mira 🎯)
* **Performance**: Indexação, subqueries e Views.
* **Stored Procedures & Triggers**: Automação dentro do banco.
* **NoSQL**: Primeiros passos com MongoDB.
